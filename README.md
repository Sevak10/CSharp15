## 🇬🇧 English

### About the Project

This repository contains practical examples and demonstrations of new language features introduced in **C# 15**, based on the .NET 11 Preview releases.

The goal is to explore upcoming C# language improvements through simple, readable, and runnable code examples.

### Topics Covered

- **Collection Expression Arguments** — specifying arguments when creating collections using collection expressions.
- **Closed Type Hierarchies** — restricting inheritance and enabling exhaustive pattern matching.
- **Extension Indexers** — adding custom indexers to existing types.
- **Labeled `break` and `continue`** — controlling nested loops using labels.
- **Unsafe Evolution** — exploring updated rules for pointer declarations and unsafe operations.
- **Union Types** — exploring union-type concepts and related examples.

### Technologies

- C#
- .NET 11 Preview
- Visual Studio

### Getting Started

1. Clone this repository.
2. Open `CSharp15.slnx` in a compatible version of Visual Studio.
3. Make sure you have the required .NET SDK and C# compiler preview support installed.
4. Select a project and run its examples.

> **Note:** Some features are experimental or preview-only and may require enabling preview language features. Availability and syntax may change in future releases.

### Purpose

This repository is a personal learning project for exploring the evolution of C# and sharing practical examples with the developer community.

### Նախագծի մասին

### Ուսումնասիրվող թեմաներ

- **Collection Expression Arguments** — collection expression-ների ստեղծման ժամանակ լրացուցիչ արգումենտների փոխանցում։
- **Closed Type Hierarchies** — ժառանգության սահմանափակում և pattern matching-ի ամբողջականության ստուգում։
- **Extension Indexers** — գոյություն ունեցող տիպերին նոր ինդեքսատորների ավելացում։
- **Labeled `break` և `continue`** — պիտակների միջոցով ներդրված ցիկլերի կառավարում։
- **Unsafe Evolution** — pointer-ների և ոչ անվտանգ գործողությունների նոր կանոնների ուսումնասիրություն։
- **Union Types** — միավորման տիպերի գաղափարի և հարակից օրինակների ուսումնասիրություն։
